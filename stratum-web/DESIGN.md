# 设计系统：运筹 Stratum

## 1. 视觉定位

Stratum 是暗色、紧凑、空间化的 Agent OS。界面以近黑点阵工作面、悬浮控制、类型化节点、细连接线和单一高亮操作建立秩序。它借鉴 PicGen 的空间比例与色彩节奏，但只承载 Stratum 的真实 Agent、模型、会话、审批和运行状态。

古典气质只存在于构图的收放、墨色层次、少量暖色和克制节奏中。界面不得使用文言包装、书法字体、仿古纹样或解释风格的小字。

目标读数：布局差异度 8/10，动效强度 5/10，视觉密度 7/10。

## 2. Token

`app/app.css` 中的标准 shadcn Token 是所有产品组件的颜色真源。业务组件只消费 `background`、`foreground`、`card`、`popover`、`primary`、`secondary`、`muted`、`accent`、`destructive`、`border`、`input`、`ring`、`chart-*` 与 `sidebar-*`。

禁止在业务组件中写 RGB、Hex 或同义颜色变量。阴影和光晕必须由标准 Token 通过透明度或 `color-mix()` 推导。品牌 SVG 可以保留自身的 mark 变量。

本产品暂时只提供暗色工作面：

- Background `#090808`
- Foreground `#F9F6F5`
- Card `#171716`
- Popover `#1C1B1B`
- Primary `#78ED9D`
- Secondary `#292727`
- Muted `#212020`
- Muted foreground `#A69C98`
- Accent `#313239`
- Destructive `#C75A50`
- Border `#32302F`
- Chart 1 / 输入与就绪 `#78ED9D`
- Chart 2 / 模型 `#EFF244`
- Chart 3 / 输出 `#65C9FF`
- Chart 4 / Agent `#B48CFF`
- Chart 5 / 错误端口 `#FF7182`

颜色只标记端口类型、运行状态、选中对象和关键动作。状态不能只依赖颜色表达。

## 3. 排版

- UI 与正文：Geist Variable
- 标题：Outfit Variable
- 数据、路径与紧凑元信息：Geist Mono Variable
- 中文回退：Noto Sans Variable

主要任务标题 24px 至 32px；节点标题与导航 12px 至 14px；正文与对话 15px 至 16px；真实状态或紧凑元数据 10px 至 12px。小字号只能承载真实字段、状态或数据，不得作为装饰眉题。

## 4. 形状与纵深

- 工具按钮 10px 圆角
- 节点、浮层和 Composer 12px 至 14px 圆角
- 顶部栏和工具轨 14px 圆角
- 普通边界 1px，选中节点允许 1px 类型色内边或顶部提示
- 阴影只用于悬浮壳层、节点与 Composer，普通内容不堆叠卡片

悬浮通过边界对比、轻微抬升和阴影变化表达。选中通过类型色边界和稳定状态表达，不做循环发光。

## 5. 产品壳层

### 桌面

- 顶部栏高 56px，距离视口 12px
- 左侧工具轨宽 56px，位于顶部栏下方
- 主工作区填满剩余视口
- 概览右侧检查器宽 320px
- 顶部只保留品牌、一级导航、当前位置、真实运行状态、新建对话和语言
- 最近对话从工具轨展开为浮层，不创建 248px 管理后台侧栏

### 移动

- 顶部栏距离视口 8px
- 工具轨隐藏，导航进入可访问抽屉
- 节点转为 358px 以内的真实单列流，不缩放桌面画布
- 检查器排在节点之后，连接线和缩放工具隐藏
- 不允许横向溢出

## 6. 概览 `/`

概览是一张运行关系图，而不是指标卡片墙。输入、Agent、模型、输出使用真实数据形成非对称四节点结构，连接线只表达可解释的关系。选择节点后，右侧检查器显示真实状态、数量、默认模型、Provider、路由或最近打开时间。

桌面以节点和连接线建立视觉重心；移动端按输入、Agent、模型、输出顺序线性排列。加载使用节点内部骨架；错误提供重试；空状态明确显示暂无数据，不生成示例。

## 7. 对话 `/chat`

新对话状态让 Composer 成为唯一主重心。结构借鉴 ai-saas 的 Prompt Input：顶部显示当前 Agent 与状态，中部是大输入面，底部左侧放 Agent、模型和思考配置，右侧保留独立发送按钮。只借鉴信息层级，不复制其浅色、营销文案或大圆角。

开始对话后 Composer 固定到底部，消息保持约 832px 单列阅读宽度。工具执行、思考、审批与错误继续使用真实事件并默认渐进展开。发送按钮桌面至少 40px、移动端至少 44px；移动端工具可横向滚动，但发送按钮不得被挤出。

## 8. 图标与控件

主要功能图标使用 Tabler Icons。品牌标志保留现有 Stratum Mark。无可见文字的按钮必须提供本地化 `aria-label`。控件必须覆盖默认、悬浮、焦点、按下、禁用、加载和错误状态。

用户已授权在必要时调整 `app/components/ui` 的 shadcn 源码以统一状态和尺寸。组件 API 与标准 Token 契约必须保持稳定；`react-bits` 与 `ai-elements` 继续保持受保护。

## 9. 动效

- CSS 负责 150ms 至 220ms 的悬浮、按下与焦点反馈
- Motion 负责抽屉、历史面板和路由状态过渡
- GSAP 负责节点错峰入场、连接线绘制和工作区空间序列
- 不允许多个库同时控制同一元素的同一属性
- 不做滚动劫持、环境式循环动画或无功能粒子
- `prefers-reduced-motion` 下直接呈现最终状态

## 10. 验证

每次视觉变更必须检查：

- `/` 与 `/chat`
- 桌面与移动
- 中文与英文
- 键盘焦点、屏幕阅读器名称和 44px 主要触控目标
- 正文与占位符对比度
- reduced-motion
- 无横向溢出
- 加载、空、错误、禁用、选中和运行状态
- 控制台无错误

## 11. 禁止项

- 不用主题化文案解释文化或科技感
- 不用无功能小字、装饰编号、伪参数或虚构状态
- 不用管理后台式固定宽侧栏、等宽卡片墙或营销 Hero
- 不用大面积渐变、玻璃卡片、全局颗粒或工作区之外的装饰网格
- 不伪造模型、Agent、会话、运行状态或结果
- 不把开发者日志常驻在最终用户界面
